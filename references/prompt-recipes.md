# 提示词配方

将用户的自然语言整理成明确指令，不让用户填写下列模板。只包含本次有用的部分，删掉不存在的素材、Logo 和人物要求。提交给工具的字段和参考图方式必须服从工具当前 schema；以下段落不是 API 参数。

## 通用结构

依次表达：

1. **目标与模式：** 新建还是编辑，海报主题、张数、画幅。
2. **输入职责：** 哪张图是人物外观、风格、原始 Logo、编辑底图；同一图有多个角色时明确列出。
3. **准确内容：** 允许的逐字文案与位置、人数、人物左右顺序、品牌素材。
4. **视觉语言：** 将 `style.preset` 翻译成字面、背光、布局、舞台与反射要求，叠加用户明确的颜色、材质与服装要求；新建默认约 2.22:1，编辑默认沿用底图比例。
5. **控制范围：** 将自由度档位翻译成具体允许变化，逐项列出锁定和可改内容；预设切换不隐式解除明确锁定。
6. **避免项：** 针对本次任务注明禁止额外文案、人物、品牌或指定不变的区域，不堆积无关负面词。

提示词中的“逐字正确”“保持外观”是执行目标，出图后仍需检查，不能作为已通过证明。

## 一句话创建：没有人物和图形 Logo

用户请求：

> 品牌字用 NOVA LAB，白字红光舞台，不要人物，横版。

适用提示词：

```text
新建一张约 2.22:1 的宽幅极简品牌舞台海报。唯一可见文案是“NOVA LAB”，左侧“NOVA”、右侧“LAB”，逐字保持。没有人物，没有图形 Logo，中央保留简洁留白；不添加角落小字或其他文字。
采用 white-red 白字红光预设：正面对称，左右巨型窄体品牌字尽量铺满横幅。字面乳白或白色发光，红色背光和边缘溢光，深红黑背景；低台阶用红色细线勾勒，地面呈现强而清楚的红白镜面反射。保留清晰字形，不把字面做成暗红色，不添加设备或无关装饰。
采用平衡档：以白色字面、红色光和正面对称为本次预设基准，在此框架内调整文字尺度、灯光强弱及舞台深度。锁定用户的文案及无人物要求；不把预设默认值转换为后续不可更改的锁定。
```

用户只说“红黑舞台”而未指定字面时，也使用默认白色字面与红光；用户明确指定红色字面时遵循其要求。画幅约定是构图目标，不承诺未经验证的原生像素尺寸。

## 可选预设：暗红立体字

用户请求：

> 主字 NOVA LAB，不要人物，使用旧版暗红立体字风格。

```text
新建一张约 2.22:1 的宽幅极简品牌舞台海报，采用 dark-red 暗红立体字预设。唯一可见文案为“NOVA LAB”，没有人物、图形 Logo 或角落小字。
深黑舞台中用巨型窄体暗红立体字作为主视觉，字面保留材质与明暗，侧面呈现明显厚度；简洁低台座、红色轮廓光、较克制的红色地面反射，保留暗部层次。
自由度为平衡档：可调整字与留白比例、光源方向和舞台深度，保持暗红立体字这一识别特征及所有锁定内容。
```

若是在现有图上切换预设，使用原图作为编辑底图并保留其比例；仅更新未锁定的风格项，继承准确文案、人物、Logo 及明确颜色和材质要求。

## 参考照片创建：接近指定风格

用户请求：

> 按上传的风格图，用我们的两人合照做品牌舞台海报，左侧 NOVA，右侧 LAB，自由度 20。

实际检查素材后形成指令：

```text
新建一张品牌舞台海报，用户未指定画幅时默认约 2.22:1。已标注的风格图仅决定视角、布局、灯光与空间，不继承其中的人物、文字、角落口号、平台名或 Logo；合照仅提供本次两人的外观及左右顺序。
恰好两人，保持原照左、右位置关系及可见的发型、眼镜、胡须和五官特征。保留原有衣着，不自动修容。左侧文案准确为“NOVA”，右侧准确为“LAB”，不增加其他文字。未提供图形 Logo，不生成图形 Logo。
采用严格档：接近风格参考的构图、字面、灯光和反射，围绕新的品牌字与两人做必要调整。面部使用自然中性照明，五官清楚，不让红色环境光覆盖脸部。
```

有实际 Logo 时补充其素材角色及结构约束，默认高置中央、避开头顶，不让人物遮住主体标志；没有 Logo 时保留中央留白或已允许的品牌文字。使用默认 white-red 时明确乳白／白发光字面、红背光和清晰红白镜面反射，使用 dark-red 时明确暗红立体字与较克制反射；用户提供的明确风格要求优先。用户指定服装时用具体换装要求替换“保留原有衣着”。不得把模板里的两人当成其他任务的默认人数。

## 连续探索：自由度高但内容锁定

用户请求：

> 自由度 80，给两个方向，人物、Logo 和文字不动，保持冷蓝。

沿用现有 brief、`style.preset` 和可访问素材，为两张图分别指定明确方向，例如“正面、留白更大、低台座”和“轻微侧向视角、品牌字纵深更强”。两张图都保留指定冷蓝配色、人数、顺序、人物外观、允许文字和 Logo 结构；white-red 的白色字面与发光特征可以搭配用户锁定的冷蓝光，不强制改回红色。只探索未锁定的布局、材质、灯光与空间，不把“80”当工具参数传入。

若旧任务锁定了构图，先保留构图；用户这句话只解锁了能从上下文明确看出的项，不擅自解除旧锁定。

## 局部编辑：换装

用户请求：

> 两人换同款黑色套头连帽卫衣，其他不动。

```text
编辑指定底图，只更换两人的上衣为同款黑色套头连帽卫衣：相同领口、面料、剪裁和抽绳样式，不增加品牌标志。
保留两人的脸部、头发、眼镜、胡须、手部、左右顺序与姿态；保留裤鞋、所有文字、Logo、背景、灯光、画幅和构图。原始人物照片仅用于外观对照，不替换编辑底图。
使换装区域的遮挡与光影自然衔接，减少对服装以外区域的重绘。
```

若原图没有 Logo、只有一人或只修改某位成员，按真实输入删改指令。使用宿主支持的编辑方式，不假设存在蒙版 API。

## 局部编辑：文字

```text
编辑指定底图，只把右侧主字从“TECH”改为“LAB”，准确拼写。保持该字组原有材质、色彩、立体厚度和视觉尺度。
其他所有文字、人物及服装、Logo、背景、灯光、构图和画幅保持原状。处理新字与原有元素的遮挡和反射关系，不添加额外文案。
```

旧文本必须来自用户或实际底图，不从这个示例复制。文字改完仍要对照非目标区域检查漂移。

## 仅导出

“内容不动，导出长边 4096”不生成新提示词，直接执行 [制作流程](workflows.md) 的本地导出分支。
