# 风格与控制

## 风格语法

保持“品牌登场”的舞台感：少量大元素、清晰主次、可辨认主体和足够留白。默认使用深色空间、单一强调色、巨型窄体主字、简洁台座或地平线、可控地面反射。并非每张图都必须加入台座、烟雾或图形 Logo。

| 维度 | 默认 | 可调整范围 |
| --- | --- | --- |
| 配色 | 红黑 | 冷蓝、其他单一强调色、用户指定色值；保留明确指定的颜色 |
| 字体表现 | 巨型窄体品牌字 | 字重、立体厚度、材质、相对尺度；中文保持清楚，不硬套窄体拉伸 |
| 空间 | 克制的舞台与少量结构 | 平台、背景深度、留白、景别、视角 |
| 灯光 | 强调色环境光，主体可读 | 光源方向、软硬、轮廓光、亮度；人脸保持自然 |
| 材质 | 哑光主体与适度反光地面 | 粗糙度、金属或其他材质、反射强弱 |
| 主体 | 默认无人 | 用户指定产品、虚构人物或有原照的真实团队 |
| 服装 | 保留原照衣着 | 仅按要求换装；“同款”包含款式、领口、面料、剪裁和标志位置 |
| 图形 Logo | 默认无 | 有实际 Logo 素材时按其轮廓、负形和方向使用 |

文案只使用本次允许清单。默认不增加口号、平台名、无关设备或装饰。用户明确要求的道具与主题可以加入，围绕同一视觉中心排布。

## 三档自由度

| 档位 | 数值范围／快捷值 | 设计决策 |
| --- | --- | --- |
| 严格 | 0–30／20 | 有风格参考时接近其视角、布局、比例与氛围，只替换必要内容；无参考时严格遵守文字风格规范 |
| 平衡 | 31–70／50，默认 | 在舞台、巨字和克制配色的框架内调整景别、灯光及字与主体比例 |
| 探索 | 71–100／80 | 允许更明显的视角、排布、空间与材质变化；只有未指定颜色时才可探索新配色 |

数字用于把自然语言转换为以上规则，不传入不存在的 `freedom`、`denoise` 等模型字段。不声称 49 与 50 会产生可测量的差别，也不把 80 解释为 80% 创意或 20% 保真。自由度 0 不代表逐像素复制。

明确档位与数值矛盾且上下文不能消解时，只澄清这一处；超出 0–100 的值说明有效范围，不静默映射成另一个意图。日常只说“更自由”时提升一档；只说“再接近参考”时降低一档，并保留所有锁定项。

探索档不能自动增删人物、修改允许文字、改变原始 Logo，或解除配色与编辑边界。用户请求多个方向才增加张数；否则输出一张。

## 独立锁定与优先级

按以下顺序合并任务，不用默认值覆盖明确要求：

1. 本轮具体修改，例如“右侧改成 LAB”或“红色改蓝色”。
2. 前序仍有效的要求与锁定，包括人数、人物顺序、精确文案和品牌素材。
3. 用户选定且实际可用的预设或参考；公共包没有私有品牌预设。
4. 默认值，以及自由度允许调整的剩余设计项。

记录 `locked` 与 `editable` 两组具体项目，避免仅写“尽量保持”。锁定可以细到“人物外观与左右顺序”“上方中文”“Logo 轮廓”“原图宽高比”，不必整项过度冻结。

| 用户请求 | 如何执行 |
| --- | --- |
| “自由度 80，人物和文字锁定，保持冷蓝” | 只探索布局、空间、材质与灯光；不修改人物、文案、配色 |
| “只换同款黑色连帽卫衣，脸和背景不动” | 服装可编辑，面部、人物顺序、背景及文字锁定；内置编辑工具可以执行 |
| “所有文字不变，只把右侧改成 LAB” | 右侧这处明确修改覆盖其旧文本，其余文字保持 |
| “更大胆一点” | 调整允许变化的视觉表达，不解锁品牌内容或自动加道具 |
| “内容完全不变，只导出 4096” | 进入非生成式导出，不靠自由度 0 重新生成 |

锁定是编辑目标，需要输出核验；除非实际保留了原始像素，不把它描述为工具提供的绝对保护。
