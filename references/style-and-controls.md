# 风格与控制

## 风格语法

保持“品牌登场”的舞台感：少量大元素、清晰主次、可辨认主体和简洁舞台。默认一张约 2.22:1 的宽幅海报（比例参考 4096×1842），自由度 50。用户明确的画幅优先；编辑已有图片且未要求改变画幅时保留原比例。像素尺寸取决于工具实际能力，不能把画幅约定写成原生 4K 保证。

## 两个风格预设

`style.preset` 独立于自由度 0–100 与 `locked`。用户说“白字红光”或“暗红立体字”即可，不需要输入字段名。选择预设本身不把其默认颜色、材质和布局写入 `locked`；另外明确要求保持或锁定的项目才随后续编辑保留。

| 预设 | 视觉基准 |
| --- | --- |
| `white-red`，默认白字红光 | 乳白或白色发光字面，红色背光与边缘溢光，深红黑背景；正面对称，左右巨型窄体字尽量铺满横幅；低台阶用红色细线勾勒，地面呈现强而清楚的红白镜面反射。参考 [默认示例](../assets/preview.png) |
| `dark-red`，可选暗红立体字 | 深黑空间，暗红色厚实立体字，字面保留材质和明暗，侧面可见厚度；简洁低台座、红色轮廓光和较克制的红色地面反射，保持暗部层次。参考 [旧版示例](../assets/preview-dark-red.png) |

默认白字红光的字面以乳白／白为主，不能因为“红黑配色”就自动变成红色字面。红色用于背光、边缘、舞台线条及其反射；控制溢光，使字形、Logo 和人脸可辨认。主字优先左右成组，但不为凑构图增加文案或拆坏单词；用户明确的排布优先。

有实际可用 Logo 时默认高置中央，留足与人物头顶的间隔，保持主体标志清楚可见。没有 Logo 时中央留白或使用已允许的品牌文字，不发明图形符号填空。两种预设均不默认加入烟雾、人物、额外口号或装饰。

| 维度 | 默认 | 可调整范围 |
| --- | --- | --- |
| 配色 | `white-red` 的白字、红光、深红黑背景 | 冷蓝、其他单一强调色、用户指定色值；保留明确指定的颜色 |
| 字体表现 | 发光乳白／白色巨型窄体品牌字 | 随所选预设调整厚度与材质；中文保持清楚，不硬套窄体拉伸 |
| 空间 | 正面对称宽幅、左右巨字、低台阶红线 | 在所选自由度内调整平台、背景深度、留白、景别与视角 |
| 灯光 | 红色背光与边缘溢光，字面清楚 | 光源方向、软硬、轮廓光、亮度；人脸保持自然中性照明 |
| 材质 | 亮字面与清晰红白镜面地面 | 随所选预设及要求调整粗糙度、金属质感与反射强弱 |
| 主体 | 默认无人 | 用户指定产品、虚构人物或有原照的真实团队 |
| 身材比例 | 新建有人物时自然协调 | 保持原样，或按“稍显修长”等具体要求自定义；身体锁定与编辑范围优先 |
| 服装 | 保留原照衣着 | 仅按要求换装；“同款”包含款式、领口、面料、剪裁和标志位置 |
| 图形 Logo | 有素材时高置中央，无素材时留白或品牌文字 | 保持原始轮廓、负形和方向；不让人头遮住主体标志 |

文案只使用本次允许清单；用户明确要求代写时，将实际采用的创作文案写入清单。不要照抄示例的角落口号、平台名或其他品牌内容。用户明确要求的道具与主题可以加入，围绕同一视觉中心排布。

## 身材比例

这个控制独立于风格预设和自由度，对真人与虚构人物均适用：

| 自然语言 | 内部模式 | 执行范围 |
| --- | --- | --- |
| 自然协调 | `natural`，新建有人物时默认 | 适度协调头身视觉关系、肩身与四肢透视、姿态和站位，让身体与场景自然衔接 |
| 保持原样 | `preserve` | 保持原照或编辑底图可见的身体比例、姿态与站位；不作身形优化 |
| 自定义，例如“稍显修长” | `custom` | 记录具体要求，优先以自然姿态、站位和透视实现适度变化，不泛化成全面美化 |

不自动瘦脸、极端拉腿、改变身份特征或原有相对身高；“自然协调”也不意味着一律变瘦或变高。原照未展示的身体部分属于生成补全，在任务记录和交付说明中标明，不能称为还原。明确锁定身体时保留；用户仅要求改背景、换文字或换衣服时，不因为默认值而顺带调整头身比例、四肢或站姿。局部任务只有明确要求调整身体时才增加对应编辑范围。

## 四角文字

按左上、右上、左下、右下分别保存准确字符串，对应 `corner_text.top_left`、`top_right`、`bottom_left`、`bottom_right`。新建时未填位置用空字符串表示“无”，不自动复制其他角的文字或用装饰文案补齐。连续编辑只更新用户点名的角，其余沿用底图；明确说“清空”才删除已存在的内容。

用户给定文字时保持字词、大小写、标点与位置。只有用户明确要求“帮我写四角文案”等代写意图时，才可起草与主题相关的创意短句，并在出图前将实际采用的逐字内容记入 brief。代写授权不包括杜撰事实、品牌全称、网址或适用平台；缺少这些信息时用不含该事实的创意短句，必须呈现时再补询必要信息。

四角作为次要信息，留足安全边距，字号可读，不抢主字、不遮挡人物或 Logo，也不贴到裁切边缘。长文案优先合理换行与调整排版，不擅自删改准确字符串。自由度仅影响允许变化的排版，不解除文案内容、指定角位或身体约束。

## 三档自由度

| 档位 | 数值范围／快捷值 | 设计决策 |
| --- | --- | --- |
| 严格 | 0–30／20 | 有风格参考时接近其视角、布局、比例与氛围，只替换必要内容；无参考时严格遵守所选预设 |
| 平衡 | 31–70／50，默认 | 保持所选预设的字面、光色及舞台特征，调整景别、灯光强度及字与主体比例 |
| 探索 | 71–100／80 | 允许更明显的视角、排布、空间与材质变化；保留所选预设的识别特征，只有未明确指定且未锁定颜色时才可探索新配色 |

数字用于把自然语言转换为以上规则，不传入不存在的 `freedom`、`denoise` 等模型字段。不声称 49 与 50 会产生可测量的差别，也不把 80 解释为 80% 创意或 20% 保真。自由度 0 不代表逐像素复制。

明确档位与数值矛盾且上下文不能消解时，只澄清这一处；超出 0–100 的值说明有效范围，不静默映射成另一个意图。日常只说“更自由”时提升一档；只说“再接近参考”时降低一档，并保留所有锁定项。

探索档不能自动增删人物、修改允许文字及四角位置、改变原始 Logo，或解除身体、配色与编辑边界。用户请求多个方向才增加张数；否则输出一张。

## 独立锁定与优先级

按以下顺序合并任务，不用默认值覆盖明确要求：

1. 本轮具体修改，例如“右侧改成 LAB”或“红色改蓝色”。
2. 前序仍有效的要求与锁定，包括人数、人物顺序、精确文案和品牌素材。
3. 用户选定且实际可用的预设或参考；公共包没有私有品牌预设。
4. 默认值，以及自由度允许调整的剩余设计项。

切换 `style.preset` 时，更新旧预设产生的字面、光色、舞台和反射默认值；保留用户明确的颜色、材质和其他锁定。例如“切换白字红光，但保持冷蓝灯光”得到白字冷蓝光，记录为 `white-red` 加颜色覆盖。只说“换预设”不能解除旧有明确锁定；“把暗红字改成白色发光字”才是对应字面颜色与材质的具体修改。

记录 `locked` 与 `editable` 两组具体项目，避免仅写“尽量保持”。锁定可以细到“人物外观与左右顺序”“上方中文”“Logo 轮廓”“原图宽高比”，不必整项过度冻结。

| 用户请求 | 如何执行 |
| --- | --- |
| “自由度 80，人物和文字锁定，保持冷蓝” | 只探索布局、空间、材质与灯光；不修改人物、文案、配色 |
| “只换同款黑色连帽卫衣，脸和背景不动” | 服装可编辑，面部、人物顺序、背景及文字锁定；内置编辑工具可以执行 |
| “身材比例自然协调，但身体保持原样” | 明确保留身体优先，不以自然协调默认值改动比例、姿态或站位 |
| “只把右上改成 MAKE IT REAL” | 更新右上准确字符串，其余四角、主字、人物与画面保持 |
| “所有文字不变，只把右侧改成 LAB” | 右侧这处明确修改覆盖其旧文本，其余文字保持 |
| “更大胆一点” | 调整允许变化的视觉表达，不解锁品牌内容或自动加道具 |
| “换成暗红立体字，人物和文字不动” | 切换至 `dark-red`，只更新未锁定的字面、灯光与反射等风格项；保留人物、文案和已有明确颜色／材质锁定 |
| “内容完全不变，只导出 4096” | 进入非生成式导出，不靠自由度 0 重新生成 |

锁定是编辑目标，需要输出核验；除非实际保留了原始像素，不把它描述为工具提供的绝对保护。
