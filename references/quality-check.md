# 质量检查与修正

先看整体，再看文字、Logo 和人脸等关键细节。把原始素材、编辑底图与本次结果区分开，按实际检查结果填写；看不清或工具无法查看时写“待检查”。没有人物或 Logo 的项目写“不适用”，不为凑检查项添加内容。

## 分项验收

| 项目 | 检查方法与通过条件 |
| --- | --- |
| 文案 | 对照 brief 逐字核对大小写、中文、标点、位置；没有扩写、缺字或额外口号。OCR 若可用仅作辅助，仍看画面 |
| 四角文字 | 分别核对左上、右上、左下、右下的准确字符串与角位；新建未填处为空白，局部编辑未指定处保持原状。代写必须有用户明确请求，事实、品牌全称、网址和平台有实际依据；安全边距、字号与亮度合适，不抢主字、不遮挡主体 |
| 人数与顺序 | 与本次要求及人物原照对照，无多余或缺失人物，左右关系正确 |
| 人物外观 | 对照脸型、五官、发型、眼镜、胡须；面部使用自然中性照明，五官清楚，无满脸红光或明显结构畸变。只能说明观察到的偏差，不编相似度分数 |
| 身材比例 | 按自然协调／保持原样／自定义及身体锁定验收头身视觉关系、肩身与四肢透视、姿态和站位；变化适度自然，无自动瘦脸、极端拉腿、身份特征或原有相对身高改变。只改背景等任务的身体应保持；原照未展示部分标为生成补全 |
| 服装与可见身体 | 保留原衣着或落实本次换装；统一服装检查款式、领口、面料和剪裁，检查可见手部与遮挡。原片未展示的部位标明为生成补全 |
| Logo | 与实际原始 Logo 对照外轮廓、比例、方向、内部负形；默认高置中央，主体标志不被人头遮挡。没有原始 Logo 时中央留白或使用已允许的品牌文字，不出现虚构品牌标志 |
| 风格预设 | 按 `style.preset`、具体要求与锁定验收。`white-red` 应有乳白／白发光字面、红背光与边缘溢光、深红黑背景、低台阶红线、清楚的红白镜面反射；`dark-red` 应有暗红厚实立体字、深黑空间、红轮廓光及较克制的红色反射。用户明确的颜色／材质覆盖优先，不把覆盖项误判成失败 |
| 布局与自由度 | 默认白字红光以正面对称、左右巨字铺满宽幅为基准；按本次自由度与锁定检查主字尺度、舞台空间、主体可读性及留白。探索变化需在允许范围内，预设切换没有偷偷解除颜色、材质或其他锁定 |
| 编辑边界 | 对比底图的非目标区域，记录文字、面部、服装、背景与构图有无可见漂移；普通视觉检查不能证明逐像素不变 |
| 输出规格 | 用实际文件信息确认像素、比例、格式。新建默认约 2.22:1，用户指定比例优先；编辑未要求改画幅时应保留底图比例。导出任务核对 JSON 报告、是否重采样及是否留边；不把比例示例 4096×1842 当作已实现的原生输出规格 |

指定修容才检查该项，例如去胡须时看上唇、嘴角、下巴；不把去胡须扩大为瘦脸或年轻化。没有修容要求时，原有外观保持是检查目标。

## 定向修正

发现具体偏差时，优先编辑对应区域并保留通过部分。默认最多两轮定向修正；用户的调用次数、时间或成本要求覆盖该默认值。每轮保留前一版本并记录改动，避免为了一个错字反复重生成整张人像。

同一错误持续出现时报告未通过项，选择有实际工具支持的替代路径：更清晰原照、减少面部重绘、单独排版文字或置入原始 Logo。没有替代能力就交付真实状态，不把未通过项改写为通过。

真人相似度最终仍由用户对照原照确认。不要仅凭一次满意出图就声称跨品牌、不同人数或所有自由度档位均已验证。

## 任务检查记录

将以下结构写入任务输出目录的 `qa-report.md`，按本次实际内容填写，不照抄示例结论：

```markdown
# 海报检查

- 输入：原照、风格参考、Logo、编辑底图的实际引用，以及各自用途。
- 输出：实际文件路径。
- 任务：新建／编辑／仅导出；style.preset、本次自由度、身材比例模式、明确覆盖项、锁定范围与画幅要求。

| 项目 | 状态 | 观察依据 |
| --- | --- | --- |
| 文案与四角 | 通过／未通过／待检查／不适用 | 逐字、角位、安全边距与来源对照 |
| 人物与 Logo | 通过／未通过／待检查／不适用 | 具体观察，不写推测评分 |
| 身材比例 | 通过／未通过／待检查／不适用 | 实际模式、身体约束与生成补全部位 |
| 风格与编辑边界 | 通过／未通过／待检查 | 与参考和底图的对照 |
| 文件规格 | 通过／未通过／待检查 | 真实尺寸、格式与导出报告 |

- 修正记录：实际修正次数、修改范围与仍未解决的问题。
- 检查限制：细节不可读、缺原始素材或无法验证的项目。
```

尺寸检查与视觉检查分开。仅导出时无需重新宣称原图人物或文案通过，只验证导出文件与内容保留方式。向用户展示图片及简短结果，内部记录不成为使用门槛。
