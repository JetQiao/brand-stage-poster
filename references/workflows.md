# 制作流程

## 素材与任务记录

先查看当前附件或实际可访问文件，记录哪些输入负责人物外观、风格、Logo 或编辑底图。不要把过期文件名当成已拿到的素材。同一图片可以有多个清楚的角色；人物原照与上一轮海报仍要区分。

仅询问执行所必需的缺失：真实团队缺照片、必须使用的图形 Logo 缺文件、编辑缺底图，以及品牌内容不明。已有文字但没有 Logo 可以直接制作文字品牌海报。明确无字场景可以没有品牌文字。用户没有提出真人需求时，不自动增加人物或索取照片。

在当前工作项目或用户指定输出位置创建 `output/<task-id>/`，不要在已安装的 Skill 文件夹里保存私人素材或任务输出。沿用同一任务记录可以支持连续修改；不同任务分目录。以下为内部记录示例，字段由代理填写，用户不必写 JSON：

```json
{
  "task": "create",
  "brand": "NOVA LAB",
  "text": [{"content": "NOVA LAB", "placement": "主视觉"}],
  "subject": {"type": "none", "count": 0, "order": []},
  "inputs": [],
  "style": {
    "preset": "white-red",
    "freedom": 50,
    "mode": "balanced",
    "palette": "白字红光、深红黑背景",
    "aspect_ratio": "2.22:1"
  },
  "locked": ["文字逐字不变", "无人物"],
  "editable": ["灯光", "字形材质", "舞台布局"],
  "output": {"count": 1, "long_edge": null, "uhd": false},
  "results": []
}
```

`task` 取 `create`、`edit`、`export`；`style.preset` 取 `white-red`（白字红光，默认）或 `dark-red`（暗红立体字）。预设、自由度与锁定分别保存。有素材时在 `inputs` 写实际路径或有效附件引用及 `roles`；人物顺序使用左侧、右侧等位置标签。用户明确值形成相应锁定，自动补全的默认审美值不自动锁定。输出后在 `results` 记录真实路径、像素与是否重采样。

生成与编辑保存实际使用的指令为 `prompt.md`；检查保存为 `qa-report.md`。仅导出记录输入、命令和输出，不编造生成提示词。宿主没有文件写入能力时，在可用交付形式中说明记录内容，不声称文件已经保存。

## 新建海报

1. 合并预设、文字、主体、画幅、自由度与独立锁定；未指定时采用一张、约 2.22:1 超宽横版、平衡档及白字红光。用户指定画幅优先；编辑已有海报且未要求改变画幅时保留原比例。具体配色、材质等锁定优先于预设，不能以切换预设为由自动解除。
2. 按 [提示词配方](prompt-recipes.md) 组织目标、参考职责、逐字文案与允许变化范围。首次创建可直接把原始人物照片、Logo 作为生成参考，不需要先有旧海报。
3. 使用宿主提供的图像工具。先遵循当前工具说明：支持的参考传递方式、数量、尺寸、参数和输出要求，以实际 schema 为准。不假设支持固定模型、蒙版、透明图层、种子或原生 4K。
4. 得到工作图后按 [质量检查](quality-check.md) 检查。内容通过再做用户需要的尺寸导出，避免把错误图片放大后当成成品。

有图像工具就直接执行已明确的制作要求；没有工具时交付 `prompt.md` 与所需素材，说明尚未生成。本技能不自行注册服务、寻找 API key 或改用其他付费平台。

## 编辑现有海报

将待修改图片指定为**编辑底图**；原始人物照与 Logo 是辅助参考，风格图不是新的编辑底图。读取上一轮 brief，更新本轮可改范围，其余明确锁定继续生效。

- **只改文字：** 指明旧文本、准确新文本、位置；锁定其他文字、人物、服装、Logo、背景和画幅。
- **只换服装：** 指定要换的成员、服装款式及可见细节；使用宿主内置编辑能力，尽量把影响范围限定到服装。面部、头发、手部、人物顺序和其他背景保持。
- **改色或构图：** 明确颜色影响哪些区域，构图允许移动哪些元素；不要把一句“更有舞台感”自动扩大为重画人物。

工具支持真实蒙版时按其文档使用；不支持时用明确的区域描述，但不能将文字约束说成像素级锁定。工具若只能整图再生成，先说明这种路径无法保证未编辑区域不变；用户要求严格保留原像素时，应使用实际可用的局部编辑／合成能力，否则明确能力缺口。

每次编辑后与底图对照，包括非目标区域。修正已明确问题不重复询问许可；若需改变目标或放弃用户要求的保留范围，说明具体取舍。

## 人物、Logo 与精确文字

**人物：** 参考原照的脸型、五官、发型、眼镜、胡须和相对左右位置。默认保留现有外观，不自动修容、去胡须或统一服装。用户要求换装时可以编辑原照片或海报，不因存在真人而拒绝正常制作。

原照没有展示的身体、服装或鞋子是生成补全，不能宣称这些部分还原本人。人脸在全图中过小时查看放大细节；需要高保真时减少面部重绘，若宿主支持保留原始人物像素的合成，可按素材条件采用。生成参考和“锁脸”提示都不等于人脸像素不变。

**Logo：** 只使用用户提供或本次明确指定且可访问的原始文件。保持外轮廓、内部负形、方向与比例；材质、厚度和光照仅在本次允许范围内变化。不从模糊风格参考猜测某个品牌的标志。没有图形 Logo 时直接使用品牌文字。

**文字：** 保留准确字符串，包含大小写、中文和指定标点；指定位置就逐处绑定。不自动将缩写扩成全称，也不添加宣传语。对精确排版要求高的任务，可在宿主确有相应能力且用户选用此路线时，先生成舞台底图，再置入原始 Logo 与文字；仍需核对透视、遮挡和反射。不要伪称当前工具具备图层或字体接口。

## 仅导出尺寸

不调用生成工具，不改内容或调色。脚本使用 Pillow 的 Lanczos 重采样并保存新文件。需要 Python 3.10+ 及 Pillow，依赖安装由项目说明提供。

从 Skill 目录执行以下命令，所有路径替换为本次实际路径；`--output-dir` 指向用户的工作输出目录，不能指向公共 Skill 目录：

```bash
python3 scripts/export_4k.py \
  --input /absolute/path/to/poster.png \
  --output-dir /absolute/path/to/project/output/task-001 \
  --prefix brand_stage \
  --long-edge 4096
```

- `--long-edge` 指长边像素，默认使用 4096；另一边按原比例计算。竖图也保持原比例。
- 另外需要 3840×2160 UHD 时增加 `--uhd`，等比例居中放入黑色画布；不拉伸、不默认裁切。
- 默认不覆盖已有输出。确需替换已有导出时增加 `--overwrite`，始终保护输入文件。

查看实际 PNG 与 JSON 导出报告，确认尺寸、比例、留边与重采样。4096 长边不等于 UHD；重采样不等于 AI 超分或原生 4K，也不会补回原图未记录的细节。用户要求原生 4K 时必须由实际生成工具能力及输出证据支持。

对脚本不支持的精确画布、裁切或超分需求，不发明命令参数；依据实际可用能力处理并说明采用的方法。交付始终给真实文件，不把命令示例当成已生成结果。
